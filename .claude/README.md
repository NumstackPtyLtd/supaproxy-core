# .claude/

Optional [Claude Code](https://claude.com/claude-code) configuration for the SupaProxy engine. Does not affect build, tests, or runtime.

## What's in here

- **hooks/** -- Pre-commit checks that block hardcoded URLs, provider-specific token formats, and committed secrets in `.ts` files.

## Skills

Skills (auditing, scaffolding, debugging) live in the central [supaproxy](https://github.com/NumstackPtyLtd/supaproxy) governance hub, not in this repo.
